# GSheetsContactFormScript
This code's purpose is to be used for user input data entered on a website to also show on a Google Sheet. Such as, a user entering information on a contact form inquiry. This code should be pasted into the Google Script App (code.gs).

How to connect with Google Form:
1. On Google Sheets, Extensions -> Apps Script
2. Paste code.gs into the Apps Script Browser
3. Deploy -> New Deployment -> Let Anyone Manage it
4. Copy Web URL
5. Paste URL into the designated area in javascript.js

   NOTE: Make sure GSheets name correlates with the HTML form's label names
